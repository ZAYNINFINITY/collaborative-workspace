## 📦 Installation Instructions

1. Clone the repository
   ```bash
   git clone https://github.com/ZAYNINFINITY/collaborative-workspace.git
   ```
2. Navigate to the project directory
   ```bash
   cd collaborative-workspace
   ```
3. Install dependencies
   ```bash
   npm install
   ```
