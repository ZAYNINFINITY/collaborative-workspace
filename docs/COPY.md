## Features (Summary)

**Real-time chat that stays on topic.** Keep conversations inside the workspace with threads, mentions, and activity context.

**Kanban that actually reflects reality.** Assign owners, set deadlines, and track progress without losing tasks in a spreadsheet.

**Docs + notes with revision history.** Capture decisions and keep living documentation next to the work.

**Team access controls.** Invite teammates, assign roles, and keep workspaces private.

**Integrations that pull work in.** Connect GitHub repositories to keep code and collaboration in sync.
